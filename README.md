F1 Tracker is a simple and user-friendly website designed to help Formula 1 fans stay up to date with the 2025 season by providing quick access to race schedules, driver standings, and constructor standings in a clean and easy-to-read format. The website allows users to view all races in one place, track how drivers are performing throughout the season, and compare how teams are competing against each other, all through a straightforward and accessible interface. This project was created with the goal of making Formula 1 data more understandable for casual viewers, especially those who are new to the sport, and was inspired by the idea of sharing F1 information with family members who recently became interested in watching races. Built using HTML, CSS, and JavaScript and hosted on GitHub Pages, the site uses publicly available Formula 1 data to display its information. Future improvements for the project include adding live race updates, incorporating qualifying results, introducing driver profiles, improving mobile responsiveness, and integrating real-time data APIs. Overall, F1 Tracker serves as an educational and personal project that demonstrates how motorsport data can be presented in a simple and engaging way for a broader audience.
